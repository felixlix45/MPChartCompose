Rendering Architecture

Layered draw pipeline — static layers cached, data layer redraws per frame

Draw Pipeline (per frame)
Layer 1: Background
drawWithCache — redraws only on size/theme change
• Fill background color
Layer 2: Grid & Axes
drawWithCache — redraws only on axis config or viewport change
• Grid lines (horizontal + vertical)
• Axis lines + tick marks
• Axis labels (formatted via lambda)
• Limit lines (e.g., day open price)
Layer 3: Data (HOT PATH)
Redraws every frame during streaming — path caching for appends
• Line paths (cubic/linear/stepped)
• Fill area under line
• Bar rectangles
• Data point circles
Layer 4: Highlights & Markers
Redraws on selection change only
• Vertical/horizontal crosshair lines
• Selected point indicator
• Value label popup
Layer 5: Overlay
drawWithCache — redraws only on config change
• Legend
• Description text

Performance Keys

✅ Zero recomposition on data change
✅ drawWithCache for static layers
✅ Path reuse on append-only updates
✅ Frame batching via Channel + withFrameMillis
✅ Viewport transform in draw phase only

Coordinate System

Data space: (x: Float, y: Float)
Viewport: visible window into data space
Pixel space: DrawScope coordinates
Transformer converts:
data → viewport → pixel
pixel → viewport → data (for touch)

WebSocket Flow

1. Tick arrives (any thread)
2. → Channel buffer
3. → withFrameMillis collector
4. → Batch into single update
5. → Atomic state swap
6. → Draw invalidation only
7. → Canvas reads new data

Key Insight: Composition vs Draw Phase

The chart composable itself rarely recomposes. Configuration (axes, style, gestures) triggers recomposition. Data changes never trigger recomposition — they only invalidate the draw phase via Modifier.drawBehind / drawWithCache. This is achieved by reading data state inside draw lambdas, not in the composable body.

// Data read happens HERE (draw phase) — not in composition
Modifier.drawBehind {
    val currentData = chartState.data  // snapshot read → draw invalidation only
    drawLineData(currentData, transformer, animationPhase)
}
